# templates

Scaffolds used by the spec intake tooling.

| Template | Produces |
| -------- | -------- |
| `spa` | Single-page application workspace: Vite, TypeScript, Tailwind, Vitest, token wiring |

## Rules

1. A template wires tokens, lint, test, and build configuration before any feature code exists.
2. Templates contain no sample content: the specification defines the feature set.
